公开项目在 `motir.co` 上有自己的地址。此外，工作区可以在 `motir.site` 下认领一个属于自己的名称，还可以在自己已拥有的域名上提供它托管的应用。

## 你的 Motir 地址 {#your-motir-address}

每个公开项目都在 `motir.co/p/ROADMAP` 提供服务，对应的项目键为 `ROADMAP`。无需认领任何东西：地址由项目键决定，并包含在每个方案中。

## 你的工作区名称 {#your-workspace-name}

工作区可以在 `motir.site` 下认领一个名称——例如 `acme` 会给出 `acme.motir.site`。Motir 为你的工作区托管的应用就在这个名称下提供服务：地址本身显示工作区的默认应用，若还没有应用，则显示一个说明这里还没有应用的页面。**公开项目永远不会在这个名称下提供服务**——项目始终留在它的 `motir.co` 地址。

工作区的所有者或管理员可以在 _工作区设置_ 的 _公开地址_ 中认领这个名称。项目设置会以只读方式显示它，并附上前往该处的链接。

名称由小写字母、数字和单个连字符组成，长度为三到六十三个字符。有一小部分名称被保留，用于 Motir 自己的主机，以及读者可能误认为是 Motir 主机的名称。

一个工作区要么有一个名称，要么没有。**没有别名，也没有任何重定向：** 重命名或释放名称后，旧地址会立即停止响应，已经分享出去的链接也会失效。

- **每 30 天只能更改一次。** 重命名和释放各算一次更改，所以先释放再重新认领也绕不过这条限制。在还不能更改的期间，面板会显示下一次可以更改的日期。
- **你放弃的名称会被保留，刚认领的除外。** 持有不到 24 小时的名称会立即回到可认领状态。持有 24 小时或更久的名称会被保留 90 天，这样其他人就无法接手原本指向你的链接；确认对话框会写明它重新可供认领的确切日期。

## 你自己的域名 {#your-own-domain}

你拥有的域名（例如 `shop.acme.com`）可以用你工作区托管的应用来响应，无论该应用运行在哪个目标上。自定义域名适用于付费方案，详见[我们的方案](/)。由工作区的所有者或管理员添加和移除；工作区里的其他人只能以只读方式查看。你的项目在 `motir.co` 上的地址和你工作区在 `motir.site` 下的名称，无论如何都会继续正常工作。

## 添加域名 {#add-the-domain}

在 _工作区设置_ 的 _自定义域名_ 中添加域名。_公开地址_ 面板中也有前往该处的链接：_改用你自己的域名_。

添加时，选择这个域名要提供工作区中的哪个应用。一个域名只提供一个应用。之后可以在该域名所在行用 _更改应用_ 改成别的应用。还没有托管应用的工作区也可以添加域名：它会以不指向任何应用的状态添加，在你选择应用之前不提供任何内容。

## 你要创建的记录 {#the-records-you-create}

域名添加后，面板会列出它需要的每一条记录，附上确切的值，每条都有复制按钮，并保留在 _显示 DNS 记录_ 下。下面的格式只是让你心里有数——用它们确认你的注册商能否创建这些记录，具体的值请从面板获取。

首先，创建一条 `TXT` 记录来证明域名归你所有。它的名称是 `_motir-verify.` 加上你的域名；大多数注册商只需要填写根域名前面的部分，如下所示：

| 类型  | 名称                 | 值           |
| ----- | -------------------- | ------------ |
| `TXT` | `_motir-verify.shop` | 显示在面板中 |

其中的令牌只属于你，请从面板复制，不要从别处复制。

然后，创建一条把域名指向 Motir 的记录。对于 `shop.acme.com` 这样的**子域名**，创建一条 `CNAME`：

| 类型    | 名称   | 值           |
| ------- | ------ | ------------ |
| `CNAME` | `shop` | 显示在面板中 |

对于 `acme.com` 这样的**根域名**，改为创建一条 `A` 和一条 `AAAA`——根域名不能使用 `CNAME`，因为它已经带有你的邮件和其他服务所依赖的 `MX` 和 `TXT` 记录。直接位于由多个部分组成的公共后缀之下的域名（例如 `acme.co.uk`）也是如此；面板知道你的域名属于哪一种，并会列出正确的记录。

| 类型   | 名称 | 值           |
| ------ | ---- | ------------ |
| `A`    | `@`  | 显示在面板中 |
| `AAAA` | `@`  | 显示在面板中 |

这些地址是 Motir 自己的，专门为客户域名保留。如果它们将来发生变化，面板会随之更新，而像本页这样的页面不会。

> 如果你的 DNS 服务商在记录上提供“代理”或“云”开关，请把它关掉：记录前面的代理会让检查看不到你的域名，证书也就无法签发。

然后选择 _立即检查_。一旦看到所有权记录，我们就会申请证书，通常需要几分钟。你可以关闭页面；状态会自动推进。

## 每种状态的含义 {#what-each-status-means}

| 状态   | 含义                                                                                              | 怎么做                                                   |
| ------ | ------------------------------------------------------------------------------------------------- | -------------------------------------------------------- |
| 未核实 | 我们还没有看到你的所有权记录。尚未向证书颁发机构申请任何内容，域名也不会响应。                    | 创建面板列出的记录，然后选择立即检查。                   |

| 失败   | “我们无法再看到你的所有权记录。”`TXT` 记录中已不再包含你的令牌，因此域名已停止响应。              | 恢复面板中显示的 `TXT` 记录，然后选择重新检查。          |
| 失败   | “_你的域名_ 不再指向 Motir。”它的 `A`、`AAAA` 或 `CNAME` 记录被修改或删除了，因此域名已停止响应。 | 把记录改回面板中显示的值，然后选择重新检查。             |
| 失败   | “无法签发证书。”证书颁发机构拒绝了签发；面板会在旁边显示该机构给出的原因。                        | 按原因所指修正（最常见的是缺少某条记录），然后选择重试。 |

| 失败   | “无法签发证书。”证书已被吊销。域名不会响应。                                                      | 选择重试，开始申请新证书。                               |

只有状态为 _已签发_ 的域名才会响应。

## 你的域名提供什么 {#what-your-domain-serves}

证书签发后，由 Motir 的边缘节点响应你的域名：它把每个请求——路径、查询、请求体和 Cookie——原样转发给该域名指向的应用，并返回该应用自己的响应。访客看到的内容取决于应用：

- **你的应用本身**：应用已发布且对所有人开放时。
- **一个说明这里还没有发布任何内容的页面**：域名没有指向任何应用，或应用尚未发布时。
- **一个说明该站点仅限成员访问的页面**：应用只对其成员开放时。成员可以通过应用的 `motir.site` 地址访问；如果有这个地址，页面会链接过去。目前，所有托管应用都只对其成员开放——向所有人开放应用的设置尚未推出——所以暂时来说，指向已发布应用的域名会显示这个页面，而不是应用本身。
- **一个说明该站点暂时无法访问的页面**：应用运行在边缘节点尚无法转发到的目标上时。一旦边缘节点能够转发，就会重新响应。
- **一个简单的“未找到”页面**：用于其他所有原因，包括域名已被移除。无论原因是什么都是同一个页面，因此绝不会让访客知道是哪一种原因。

这些页面周围都不带 Motir 自己的网站，也都不会被搜索引擎收录。

Motir 不会在你的域名上添加任何自己的重定向、规范链接、robots 文件或站点地图。这些由你的应用自行定义。

## 一个工作区里的两个域名 {#two-domains-on-one-workspace}

一个工作区可以连接多个域名，上限以其方案包含的数量为准。每个域名指向自己的应用，在各自的行中选择。Motir 不会把任何一个域名排在其他域名之上，也不会在它们之间重定向：每个域名都独立响应，提供它所指向的应用。

## 移除域名 {#removing-a-domain}

在域名所在行选择 _移除_。域名会在大约半分钟内停止提供你的应用，此后响应“未找到”页面。不会保留任何东西：你以后可以重新添加它，其他工作区只要用自己的 `TXT` 记录证明所有权，也可以添加它。你在 DNS 服务商处的记录需要你自己删除。移除域名不会改变应用本身，应用会继续在它的其他地址上响应。

## 如果出现故障 {#if-something-is-not-working}

几乎所有失败都源自以下四种错误，每一种在面板里的表现各不相同。

- **在根域名上使用 CNAME。** 大多数注册商会接受它，但它不起作用。症状是域名一直停留在 _处理中_ 或变为 _失败_。请改用上面的 `A` 和 `AAAA` 记录。
- **DNS 服务商在记录前面充当代理。** 如果你的服务商提供流量代理或加速，就会对我们隐藏真实的记录。症状是 _处理中_ 一直不结束。请为这些记录关闭代理。
- **过时的所有权记录。** 如果你移除后又重新添加了域名，令牌已经变了。症状是明明有一条 `TXT` 记录，状态却是 _未核实_。请把它的值换成面板当前显示的值。
- **所有权记录后来被删除。** 已生效域名的 `TXT` 记录消失后，域名会继续响应，直到我们的定期检查发现为止，这通常在大约一小时内发生；随后状态变为 _失败_，域名停止响应。请恢复记录并选择重新检查。
